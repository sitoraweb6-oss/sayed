# Sayed Ahmad — Portfolio & Digital Solutions

Personal portfolio and business website of **Sayed Ahmad**, founder of [Sitora Web](https://sitora.org) — a web development studio crafting high-performance websites for ambitious businesses.

## About

This site presents Sayed's work, services, and approach as a web developer and digital solutions partner: business websites, WooCommerce stores, landing pages, redesigns, and ongoing maintenance — built with performance, user experience, and business growth in mind.

## Features

- Modern, responsive portfolio layout with smooth animations
- Service offerings and process overview
- Project/case-study showcase sections
- Contact and inquiry flow
- AI-assisted interactive elements

## Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS 4, React Router 7, Motion, Lucide icons
- **Build:** Vite 8, Bun
- **Backend:** Express (bundled Node server via esbuild), Supabase, Google Gemini AI

## Getting Started

### Prerequisites

- Node.js 18+ (or Bun)

### Installation

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:3000`.

### Build for production

```bash
npm run build
```
