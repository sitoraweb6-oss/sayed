# Founder Story Image Assets

Place your custom WebP images in this directory to automatically feature them on the **Founder Story** (`/about`) page and homepage founder preview:

- **`founder.webp`** *(Primary)*: Personal founder portrait of Sayed Ahmad (recommended aspect ratio: 4:5 or 1:1, portrait orientation). This is also displayed on the homepage preview.
- **`journey.webp`** *(Optional)*: Workspace, desk setup, or journey milestone photo.
- **`marketing-background.webp`** *(Optional)*: Early career, marketing campaigns, or strategic background visual.
- **`sitora-web.webp`** *(Optional)*: Studio workspace, client presentation, or Sitora Web brand visual.

### Image Guidelines:
- Format: `.webp`
- Keep file names exact: `founder.webp`, `journey.webp`, `marketing-background.webp`, `sitora-web.webp`.
- If an image file is updated or replaced with the same name, the portfolio will automatically render the new photo without requiring any code changes.
- If an optional image is absent, the storytelling layout will automatically render a balanced editorial typography layout without broken image icons.
