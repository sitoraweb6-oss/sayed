# Portfolio Project Images

Place project thumbnail and case study preview images in this directory.

Recommended specs:
- Aspect ratio: 16:11 or 16:9
- Format: WebP or optimized PNG/JPG
- Filename pattern: `portfolio-1.webp`, `portfolio-2.webp`, etc. (or descriptive slug names matching project slugs)
- Typical resolution: 1280x880 or 1600x1100 for crisp Retina display
